● C'est un verrouillage de fichiers, pas une vraie erreur de build. Le message clé :

  ▎ 2 busy Daemons could not be reused … a process has files open … fichiers lintVitalAnalyzeRelease

  Traduction : un autre processus tient le dossier app\build ouvert — presque certainement Android Studio (tu as le projet ouvert ; il lance son propre
  daemon Gradle qui fait un lintVitalAnalyzeRelease en arrière-plan). clean ne peut donc pas supprimer le dossier.

  Le plus simple : ne fais PAS clean

  Il n'est pas nécessaire pour générer l'APK. Gradle gère l'incrémental. Lance directement :

  .\gradlew :app:assembleRelease

  Si tu veux vraiment nettoyer d'abord

  Il faut libérer le dossier app\build :

  # 1. Arrêter tous les daemons Gradle
  .\gradlew --stop

  # 2. Fermer Android Studio (ou au moins arrêter son build/sync en cours)
  #    → c'est lui qui verrouille app\build via lintVitalAnalyzeRelease

  # 3. Supprimer le dossier build à la main
  Remove-Item -Recurse -Force .\app\build

  # 4. Générer le release
  .\gradlew :app:assembleRelease

  Si Remove-Item refuse encore (fichier toujours verrouillé)

  Trouve qui tient le dossier, puis relance :
  .\gradlew --status      # liste les daemons Gradle
  Et vérifie qu'aucune fenêtre Android Studio / terminal n'est positionnée dans app\build.

  Recommandation

  Va au plus simple : saute le clean et lance juste .\gradlew :app:assembleRelease. L'APK sortira dans :
  app\build\outputs\apk\release\app-release.apk
